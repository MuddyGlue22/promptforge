# Gallery prompts (OpenMov)

12 characters for the Tavern Portraits gallery, generated by the builder itself, spread across four OpenMov text-to-image models (three each).

## Before you start

- **Use paid credits.** OpenMov's commercial licence is "subject to payment of applicable fees", free images are watermarked, and Alibaba's terms (Qwen, WAN) make free trials evaluation-only.
- **Save OpenMov's terms as a PDF** the day you generate (browser: File → Export as PDF on https://openmov.ai/terms-and-conditions). It's your record of what you agreed to.
- **Don't use the "General" model**; OpenMov doesn't say which model it is, so its terms can't be checked.

## For every image

- Paste the prompt exactly as written.
- Aspect ratio **2:3 portrait** where the model offers it; otherwise the closest portrait ratio (the gallery shows every image at its own shape).
- **Download the original file and keep it untouched.** Don't screenshot, re-save, convert or rename the extension. The original keeps its provenance data (e.g. Seedream's C2PA Content Credentials), which the gallery will link to.
- Save it as `gallery/images/<file name>.<whatever extension it downloads as>`.
- If you switch model or change anything, write it under the prompt so the gallery notes stay accurate.
