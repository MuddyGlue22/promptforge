# Gallery prompts

12 characters for the Tavern Portraits gallery, generated by the builder itself.

**For every image:**

- Aspect ratio **2:3 portrait** (e.g. 1024×1536) so the gallery grid lines up.
- Save as `gallery/images/<file name>` (PNG or JPG is fine; I'll resize and compress).
- The suggested model spreads the set across siray.ai's providers. Swap freely, but note which model you actually used.
- Avoid the Midjourney and "Spicy" endpoints (see the terms notes in the chat).
- The last line of each prompt is tuned for the suggested model. If you switch a FLUX image to another model (or the other way round), ask me for the matching version, or set **Image model** in the builder.
- If a result is off, regenerate a couple of times before changing the prompt; note anything you had to change.
